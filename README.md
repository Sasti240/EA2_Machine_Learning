## Descripción

Este proyecto busca aplicar técnicas de Machine Learning a un conjunto de datos de ventas de viviendas de King County, Washington, Estados Unidos.

Se desarrollarán dos modelos: uno de regresión lineal para predecir el valor de las viviendas y otro de clasificación para agruparlas en dos categorías según su precio.

## Dataset

- **Nombre:** House Sales (King County).
- **Fuente:** Hugging Face Datasets.
- **Repositorio:** https://huggingface.co/datasets/inria-soda/tabular-benchmark
- **Archivo:** `reg_cat/house_sales.csv`.
- **Registros:** 21.613.
- **Columnas:** 18.

Los datos incluyen características de las viviendas, como habitaciones, baños, áreas, ubicación y precio.
